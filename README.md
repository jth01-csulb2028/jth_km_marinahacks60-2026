# C++ Visuali(C)er
*get it? visuali(C)er?*

a python program dedicated to visualizing beginner C++ code

inspired by [Python Tutor](https://pythontutor.com/visualize.html#mode=display)

## What it supports

- Header files
    - [ ] Classes
    - [ ] Methods
    - [ ] Variables
    - [ ] Macros for defining the header file
    - [ ] Macros **OUTSIDE** of decleration
    - [ ] Pragma declaration

- Cpp files
    - [ ] Header dependencies
    - [ ] Classes
    - [ ] Methods
    - [ ] Variables
    - [ ] Namespaces
    - [ ] Macros

### Some examples of what aren't suppored

- namespaces
